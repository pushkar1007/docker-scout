Docker Scout


Docker Scout is an opensource lightweight self-hosted Docker management platform written in Go, designed for microservice-heavy backend projects and software enthusiasts. It solves the chaos of scaling microservices by letting devs monitor, manage, and troubleshoot every layer of their server stack in one interactive place.

Core Features

  • View all containers (running & stopped) with status, uptime, and resource metrics.
  • Browse all Docker images and their details.
  • Live metrics per container: CPU usage, memory, network traffic and other meta-data.
  • Network & group management: create networks, attach containers, and visualize groups.
  • A A Reverse Proxy that automatically forwards requests to containername.localhost, assuming microservices run on port 3000.
  • Volume management and inspection directly from the dashboard.
  • Spin up/down container groups for rapid experimentation.
  • A compose generator tool lets developers select the Docker images they need and instantly generates a ready-to-use Compose file

Architecture Overview

  • API Server: Provides container, network, and volume data to the frontend.
  • Reverse Proxy: Routes traffic automatically to containers running on port 3000.
  • Frontend Dashboard: Displays live metrics, networks, volumes, and proxy mappings in an intuitive interface.
  • Docker Compose: Spins up all components instantly for demo or hackathon use.

Network & Group Management

Containers attached to the same network are automatically grouped for easy visualization. Users can spin up or down groups of containers directly from the dashboard, enabling rapid testing of microservice setups without touching the CLI.

Quick Start

Getting started is simple—no coding required:

Step 1: Clone the repository

git clone https://github.com/pushkar1007/docker-scout.git

Step 2: Move into the project directory

cd docker-scout

Step 3: Start all services

cd proxy
docker compose up
cd server
docker compose up
cd frontend
npm run dev

Step 4: Explore the dashboard and proxy

Frontend → http://localhost:3000
Reverse Proxy → containername.localhost
→ proxy accepts all the requests(0.0.0.0) through proxynet {default net is proxy-net}

Everything you need view containers, images, networks, volumes, spin up groups, and test reverse proxy routing—is accessible directly from the Docker Scout dashboard.
